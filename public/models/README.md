# Dental arch and aligner study

The source mesh `makehuman-teeth-source.obj` is MakeHuman's teeth_base system
asset, explicitly released under CC0 in September 2020. Original copyright
holders: Data Collection AB, Joel Palmius, Jonas Hauquier. Its license notice
is preserved in the OBJ header.

Source and license listing:
https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html

Downloaded from:
https://files2.makehumancommunity.org/asset_packs/makehuman_system_assets/makehuman_system_assets_cc0.zip

CC0: https://creativecommons.org/publicdomain/zero/1.0/

Adaptations: selected lower dental crowns, centered and leveled the arch,
subdivided the mesh, and derived a joined translucent shell for an illustrative
aligner animation. This is a design visualization, not a manufacturing model
or a patient scan. `scripts/prepare-aligner.py` reproduces the JSON mesh.
